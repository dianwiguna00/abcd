BAGIAN 01 · TUJUAN PEMBELAJARAN

Ayo Menemukan Titik Potong dan Menggambar Grafik!

🎯 Tujuan Pembelajaran

Melalui kegiatan mengolah tabel dan menggambar pada bidang koordinat Kartesius, peserta didik mampu menentukan titik potong terhadap sumbu-X dan sumbu-Y serta menggambar grafik persamaan garis lurus dengan benar.

🔎 Apersepsi

Bayangkan denah taman sekolah yang memiliki dua jalur lurus. Denah menggunakan sumbu mendatar dan tegak sebagai acuan. Ketika jalur memotong salah satu sumbu, titik perpotongan itu dapat dibaca sebagai koordinat. Kita dapat membuat tabel pasangan koordinat untuk membantu menggambar jalur tersebut secara tepat.

💡 Pertanyaan Pemantik

  1. Bagaimana menentukan titik potong garis dengan sumbu-X dan sumbu-Y dari persamaannya?
  2. Mengapa nilai y harus nol ketika mencari titik potong sumbu-X?
  3. Bagaimana tabel pasangan (x, y) membantu kita menggambar grafik garis lurus?

✅ Indikator Keberhasilan

  • Menjelaskan makna titik potong sumbu-X dan sumbu-Y.
  • Menentukan titik potong dengan mensubstitusikan y = 0 atau x = 0.
  • Mengolah persamaan menjadi tabel pasangan koordinat.
  • Meletakkan titik pada bidang Kartesius dan menghubungkannya menjadi garis lurus.
  • Memeriksa kesesuaian grafik dengan persamaan.

🧭 Peta Belajar

  • Mengenali sumbu-X, sumbu-Y, dan titik asal.
  • Menentukan kedua titik potong.
  • Menyusun tabel nilai x dan y.
  • Memplot pasangan koordinat.
  • Menghubungkan titik dan membaca grafik.

🌍 Manfaat dalam Kehidupan Sehari-hari

Grafik garis lurus membantu membaca denah, membandingkan jarak dan waktu, serta memahami hubungan dua besaran yang berubah secara teratur. Titik potong dapat menunjukkan kondisi awal atau saat suatu nilai menjadi nol.

BAGIAN 02 · MATERI & SIMULASI

Menentukan Titik Potong dan Menggambar Grafik

Gunakan persamaan, tabel pasangan koordinat, dan bidang Kartesius untuk membangun grafik secara runtut.

1. Mengenal titik potong sumbu

Bidang koordinat Kartesius memiliki sumbu-X (mendatar) dan sumbu-Y (tegak). Keduanya berpotongan di titik asal O(0, 0).

Titik potong sumbu-X: titik pada garis ketika y = 0, berbentuk (x, 0).

Titik potong sumbu-Y: titik pada garis ketika x = 0, berbentuk (0, y).

2. Cara menentukan titik potong dari persamaan

Untuk persamaan garis y = mx + c, lakukan substitusi sesuai sumbu yang dicari.

Titik potong sumbu-X

Atur y = 0, lalu selesaikan nilai x.

0 = mx + c, sehingga x = −c/m (jika m ≠ 0).

Titik potong sumbu-Y

Atur x = 0.

y = m(0) + c = c, sehingga titiknya (0, c).

Contoh: y = 2x + 4.

  1. Sumbu-X: 0 = 2x + 4, maka x = −2. Titik potongnya (−2, 0).
  2. Sumbu-Y: x = 0, maka y = 4. Titik potongnya (0, 4).

3. Mengolah tabel pasangan koordinat

Masukkan beberapa nilai x ke persamaan, kemudian hitung nilai y. Setiap baris menghasilkan satu titik (x, y).

Untuk y = 2x + 4:

x = −3 menghasilkan y = −2; x = −2 menghasilkan y = 0; x = 0 menghasilkan y = 4; dan x = 1 menghasilkan y = 6.

Pasangan koordinatnya antara lain (−3, −2), (−2, 0), (0, 4), dan (1, 6).

4. Menggambar grafik pada bidang Kartesius

  1. Gambar sumbu-X mendatar dan sumbu-Y tegak serta tandai titik asal.
  2. Tentukan skala yang sama dan beri tanda bilangan pada kedua sumbu.
  3. Plot beberapa titik dari tabel, termasuk titik potong jika terlihat.
  4. Hubungkan titik-titik dengan garis lurus menggunakan penggaris.
  5. Periksa apakah titik-titik pada grafik memenuhi persamaan.

Minimal dua titik berbeda cukup untuk menentukan satu garis lurus. Titik tambahan membantu memeriksa ketepatan gambar.

5. Simulasi interaktif: ubah persamaan dan amati grafik

Ubah nilai gradien (m) dan konstanta (c). Amati titik potong, tabel nilai, dan grafik yang terbentuk. Gunakan nilai bilangan bulat agar mudah dibaca.

Titik kuning: titik potong sumbu. Titik biru: pasangan koordinat dari tabel.

BAGIAN 04 · REFLEKSI

Refleksi Pembelajaran

Periksa kembali pemahamanmu tentang titik potong dan grafik persamaan garis lurus.

📝 Cek pemahaman diri

⭐ Rangkuman

  • Titik potong sumbu-X memiliki koordinat (x, 0), sehingga diperoleh dengan menetapkan y = 0.
  • Titik potong sumbu-Y memiliki koordinat (0, y), sehingga diperoleh dengan menetapkan x = 0.
  • Tabel nilai memuat pasangan koordinat yang memenuhi persamaan garis.
  • Setiap pasangan koordinat dapat diplot sebagai titik pada bidang Kartesius.
  • Dua titik berbeda dapat dihubungkan menjadi grafik garis lurus; titik tambahan membantu memeriksa ketepatan.
Pesan pembelajaran

Kerjakan dengan urut: tentukan titik potong, buat tabel pasangan koordinat, plot titik, lalu hubungkan menjadi garis lurus. Selalu periksa kembali posisi titik dan persamaannya.
